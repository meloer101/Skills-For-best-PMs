# Edge Case Matrix

> **Usage**: 不要只写"invalid input"。逐类别扫描下面 8 个边界类型，每类至少问一遍「这里会怎么坏？」。每行给出**预期行为**（而不是"报错"这种非行为描述）。示例行标了 *(example)*，替换为你的真实场景。

## 边界类别框架（逐类扫描）

| # | 类别 | 触发场景 | 预期行为 | 风险等级 |
|---|------|----------|----------|----------|
| 1 | **状态转换** | 对象处于非法/中间态时执行操作（如对已删除项再次删除、对草稿态发布） | | High / Med / Low |
| 2 | **并发/竞态** | 两个请求同时改同一资源；双击提交 | | |
| 3 | **空状态/冷启动** | 首次使用、零数据、列表为空、新用户无历史 | | |
| 4 | **权限矩阵** | 未登录 / 越权 / 角色不足 / 会话过期 | | |
| 5 | **数据量极值** | 0 条、1 条、超长文本、超大文件、分页边界、上限+1 | | |
| 6 | **幂等/重试** | 网络重发、超时后重试、重复回调 | | |
| 7 | **网络/服务失败** | 下游超时、依赖不可用、部分成功 | | |
| 8 | **首次使用/引导** | 权限未授予、未完成 onboarding、缺前置配置 | | |

## 示例（社交产品「发帖」功能）

| # | 类别 | 触发场景 | 预期行为 |
|---|------|----------|----------|
| 1 | 状态转换 | 对已删除的草稿点"发布" *(example)* | 提示"草稿已不存在"，返回列表，不创建帖子 |
| 2 | 并发/竞态 | 用户双击"发布" *(example)* | 幂等键去重，仅创建 1 条，第 2 次返回同一结果 |
| 3 | 空状态 | 内容为空点发布 *(example)* | 按钮置灰或前端拦截，不发请求 |
| 4 | 权限 | 会话过期后发布 *(example)* | 401 → 引导重新登录，本地草稿不丢失 |
| 5 | 数据量极值 | 正文超过 5000 字上限 *(example)* | 输入框实时计数并阻止超限，服务端二次校验 |
| 6 | 幂等/重试 | 发布超时后客户端重试 *(example)* | 携带同一 request-id，服务端识别为同一次提交 |
| 7 | 服务失败 | 图片存储服务不可用 *(example)* | 文本先落库，图片标记 pending 异步补传，告知用户 |
| 8 | 首次使用 | 未授予相册权限就插入图片 *(example)* | 触发权限申请，拒绝后允许纯文本发布 |
